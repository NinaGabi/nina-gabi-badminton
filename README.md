# ShuttleHaus – Badminton Shop Prototype

Static storefront prototype for badminton equipment, built for GitHub Pages.

## Included
- Responsive German storefront
- Product/category filtering
- Local browser cart (localStorage)
- Order inquiry via email
- German legal-content placeholders
- No external framework or build step

## Preview
Open `index.html` locally or publish the repository with GitHub Pages.

## Before real sales
Replace all placeholder contact information and have the following completed/reviewed for Germany:
- Impressum
- Datenschutzerklärung
- Widerrufsbelehrung + Muster-Widerrufsformular
- Pricing/shipping disclosures
- Payment provider and checkout
- Product, tax and inventory data
- Consumer-law compliance

## Codex handoff
Clone the repository and run Codex from the repository root. Suggested first task:

> Inspect this static shop without changing files. Propose a migration path to a production-ready shop with a real product database, secure checkout, order management and deployment. Preserve the current visual identity.
